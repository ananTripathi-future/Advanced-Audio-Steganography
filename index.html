Dual-Layer Security Architecture

How the system achieves both plausible deniability and cryptographic integrity.

Layer 1

Cryptographic Confidentiality

The plaintext is encrypted with Fernet (AES-128 in CBC mode with HMAC-SHA256). The symmetric key is derived from the user's password using SHA-256 hashing, ensuring brute-force resistance.

AES-128 / 256 CBC
HMAC-SHA256
Layer 2

Identity Handshake Binding

Before encryption, the payload is structured as Sender||Receiver||Message. Decryption requires exact proof of both sender and receiver identities, preventing unauthorized extraction by third parties.

Zero-Trust Handshake
Man-in-the-Middle Defense
Layer 3

LSB Audio Steganography

The encrypted bitstream is embedded into the Least Significant Bit (LSB) of cover audio sample bytes. Modifying the 8th bit introduces a minute amplitude difference (< 0.39%) completely imperceptible to the human auditory system.

Imperceptible LSB
Plausible Deniability
