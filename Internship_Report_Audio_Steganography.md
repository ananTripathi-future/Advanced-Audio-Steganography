## 1. Introduction
### 1.1 What is Steganography?
Steganography is the practice of concealing a file, message, image, or video within another file, message, image, or video. Unlike cryptography, which focuses on making a message unreadable, steganography focuses on hiding the very existence of the message.

### 1.2 Audio Steganography
Audio steganography is a technique used to transmit hidden information by modifying an audio signal in an imperceptible manner. This project utilizes the **Least Significant Bit (LSB)** insertion method, which is one of the most common and effective ways to hide data in digital audio files (specifically `.wav` format).

## 4. System Architecture & Design

### 4.1 LSB (Least Significant Bit) Algorithm
The core of the system is the LSB algorithm. 
1. The secret message is converted into a binary stream.
2. The system reads the bytearray of the audio frames.
3. The last bit of each audio byte is replaced with one bit of the secret message.
4. Because the change is so minute (1/256th), the human ear cannot detect the difference in audio quality.

### 4.2 Security Layers
To prevent unauthorized access, the system implements three layers of security:
1. **Passphrase Encryption:** The message is encrypted using **Fernet (AES)**. The key is generated by hashing the user's password with **SHA-256**.
2. **Identification Handshake:** The message is bundled with the Sender and Receiver's email addresses (`Sender||Receiver||Message`).
3. **Identity Verification:** During extraction, the user must provide the exact Sender and Receiver emails. If they don't match the hidden data, access is denied.

### 4.3 Key Distribution
The system uses **Gmail SMTP** to automatically send the decryption password and instructions to the receiver's inbox, ensuring a seamless and secure "Out-of-Band" key exchange.

## 5. Implementation Details

### 5.1 Key Functions
- `generate_key_from_password(password)`: Hashes a string password into a 32-byte URL-safe base64 key for Fernet encryption.
- `embed_data()`: The main logic for encoding. It converts text to binary, modifies audio frames, and saves the new file.
- `extract_data()`: Reverses the LSB process to pull bits from the audio and decrypts the payload.
- `background_send_email()`: A threaded function that sends the decryption details to the receiver without freezing the GUI.
